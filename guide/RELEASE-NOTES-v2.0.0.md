# BSLView v2.0.0

Большой выпуск: формы 1С теперь выглядят почти как в конфигураторе, появился инспектор элементов, просмотр отчётов SARIF и инструменты для создания макетов печатных форм из Excel с помощью AI-агента.

## Главное

- **Формы как в конфигураторе.** Раскладка форм выверена на десятках реальных форм.
- **Правка форм AI-агентом.** Агент добавляет, переносит и удаляет элементы управляемой формы, меняет их свойства, реквизиты и команды формы и проверяет форму на ошибки. Правка точечная: остальной `Form.xml` не меняется.
- **Макеты печатных форм из Excel.** AI-агент (Claude Code, Cursor, Codex, VS Code Chat) может превратить `.xlsx` в `Template.xml`, разметить области и параметры, настроить оформление, печать и колонтитулы — и сразу показать результат.
- **Объекты метаданных.** XML объекта конфигурации открывается как окно объекта в конфигураторе: реквизиты, табличные части, формы и макеты с типами, связи объекта по всей конфигурации и роли с правами на него.
- **Отчёты SARIF.** Результаты проверок кода bsl ls и bsl-analyzer открываются как дерево замечаний по объектам или по правилам, с русскими названиями и переходом к строке модуля.

## Total Commander и BSLEdit

- Окно объекта метаданных: двойной щелчок открывает форму, макет или модуль в том же окне, «Назад» (`Alt+←`) возвращает к объекту; справка объекта.
- Закладка «Роли»: роли с правами на объект и фильтр по правам.
- Инспектор элемента формы: свойства, тип данных, путь к данным.
- События формы ведут прямо к обработчику в модуле, а в модуле видно, какому элементу назначен обработчик.
- Поиск по структуре формы с полными путями элементов и по путям к данным.
- Кнопка «Вписать по ширине» и снимок всей формы в PNG.
- Безопасное сохранение: если файл изменили извне, правка не затрёт чужие изменения.
- Формы с большим количеством команд и картинок открываются быстрее.
- Модуль формы правится прямо на вкладке «Модуль» и сохраняется вместе с формой.
- Тема по умолчанию светлая, выбор кнопкой запоминается.
- BSLEdit запоминает размер и положение окна.

## MCP-сервер для AI-агентов

- Превью открывается в скрытом браузере и не мешает работе; окно показывается только по просьбе.
- Новые инструменты макетов: конвертация из Excel, правка, просмотр разметки и проверка макета.
- Инструменты форм: список элементов, проверка и правка формы (`list_form_elements`, `validate_form`, `edit_form`).
- Правку форм и макетов можно отключить (`--no-form-edit-tools`, `--no-template-edit-tools`), оставив агенту только просмотр.

## Расширение VS Code

- Инструменты форм и макетов доступны в VS Code Chat; настройки `formEditTools` и `templateEditTools` позволяют выключить правку.
- Сервер доступен по HTTP (`http://127.0.0.1:47391/mcp`) для Claude Code, Cursor, Codex и других агентов, пока открыт VS Code.
- Превью открывается во встроенном браузере VS Code, панель элементов можно скрыть.

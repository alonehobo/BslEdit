# 1C Form Viewer — MCP-сервер для AI-агентов

MCP-сервер даёт AI-агенту (Claude Code, Cursor, Codex, VS Code Chat и другим)
«глаза» на формы и макеты 1С: агент открывает `Form.xml`, `Template.xml` или
MXL, видит, как они выглядят, делает снимки и переходит к нужным элементам. А
ещё — правит управляемые формы, собирает макеты печатных форм из Excel и правит
их.

Сервер — один `exe` для Windows x64. Node.js, npm и 1С не нужны.

На Linux и macOS работает Node.js-вариант того же сервера: те же инструменты
и тот же протокол, запуск из исходников репозитория — см.
[README пакета](../packages/1c-form-viewer/README.md#nodejs-сервер-linux-macos-windows).

## Установка

1. Скачайте `1c-form-viewer-native-<версия>-win-x64.zip` со страницы
   [Releases](https://github.com/alonehobo/BslEdit/releases).
2. Распакуйте **целиком** в постоянную папку, например
   `C:\Tools\1c-form-viewer-native`. Рядом с `1c-form-viewer.exe` должна
   остаться папка `app`.
3. Подключите сервер к своему агенту (ниже).

Нужен Microsoft Edge или Google Chrome: превью рисуется в скрытом окне браузера
и на экране не появляется. Если попросить агента «покажи форму на экране»,
откроется обычное окно.

> Пользователям VS Code ничего скачивать не нужно — сервер уже встроен в
> [расширение](vscode.md). VS Code Chat видит его сам, а Claude Code, Codex,
> Cursor и другие агенты подключаются по адресу `http://127.0.0.1:47391/mcp`
> ([подробнее](vscode.md#claude-code-codex-cursor-и-другие-агенты)).

## Подключение

В примерах сервер лежит в `C:\Tools\1c-form-viewer-native`, а выгрузка
конфигурации — в `C:\Path\To\Workspace`. Параметр `--root` ограничивает папки,
которые сервер может читать и изменять; его можно повторить для нескольких
папок.

### Claude Code

```powershell
claude mcp add --transport stdio --scope local one-c-form-viewer -- "C:\Tools\1c-form-viewer-native\1c-form-viewer.exe" --stdio --root "C:\Path\To\Workspace"
```

Проверка: `claude mcp list` или `/mcp` в сессии.

### Cursor

`~/.cursor/mcp.json` (или `.cursor/mcp.json` в проекте):

```json
{
  "mcpServers": {
    "oneCFormViewer": {
      "type": "stdio",
      "command": "C:\\Tools\\1c-form-viewer-native\\1c-form-viewer.exe",
      "args": ["--stdio", "--root", "C:\\Path\\To\\Workspace"]
    }
  }
}
```

Проверка: Cursor Settings → Tools & MCP.

### Codex

```powershell
codex mcp add one_c_form_viewer -- "C:\Tools\1c-form-viewer-native\1c-form-viewer.exe" --stdio --root "C:\Path\To\Workspace"
```

Или в `~/.codex/config.toml`:

```toml
[mcp_servers.one_c_form_viewer]
command = "C:\\Tools\\1c-form-viewer-native\\1c-form-viewer.exe"
args = ["--stdio", "--root", "C:\\Path\\To\\Workspace"]
startup_timeout_sec = 20
tool_timeout_sec = 120
```

### Другие агенты

Любой клиент с поддержкой локальных STDIO-серверов: команда — путь к
`1c-form-viewer.exe`, аргументы — `--stdio --root <папка>`.

## Просмотр форм и макетов

Писать имена инструментов не нужно — достаточно попросить обычными словами:

- «Покажи, как выглядит форма документа РеализацияТоваровУслуг»
- «Сделай снимок вкладки Товары»
- «Сравни расположение элементов формы с этим скриншотом»

| Инструмент | Что делает |
|---|---|
| `open_preview` | Открывает `Form.xml`, `Template.xml` или MXL. Понимает и описатель `Forms/Имя.xml` |
| `capture_preview` | Снимок PNG: видимая часть, вся форма или один элемент |
| `preview` | Всё остальное по `operation`: `inspect` — элементы, страницы, вкладки и прокручиваемые области; `select` — выделить элемент, открыв его вкладку; `switch_tab`; `scroll` — форма, таблица или табличный документ; `reload` — перечитать файл; `url` — адрес для клиента со своим браузером; `close` |

Инструменты просмотра никогда не изменяют файлы.

## Макеты печатных форм из Excel

Агент может взять печатную форму, свёрстанную в Excel, и сделать из неё макет
1С — с областями и параметрами, готовый для `ПолучитьОбласть`.

### Что переносится из Excel

Текст, шрифты, цвета и заливка, рамки, выравнивание, ширины колонок и высоты
строк, объединённые ячейки, числовые форматы и форматы дат, параметры страницы,
область печати, колонтитулы и картинки.

Разметку можно заложить прямо в Excel:

- именованный диапазон → область макета;
- ячейка с текстом ровно `[Имя]` → параметр;
- текст с `[Имя]` внутри → шаблон.

Не переносятся формулы (остаются значения), фигуры и диаграммы, условное
форматирование и сквозные строки печати — агент перечислит это в итоговой
сводке. Существующий макет перезаписывается только с явного разрешения.

### Что агент умеет делать с макетом

| Инструмент | Что делает |
|---|---|
| `convert_xlsx_to_template` | Делает `Template.xml` из `.xlsx` и сразу показывает результат |
| `list_markup` | Показывает разметку: области, параметры, расшифровки, настройки печати, колонтитулы |
| `validate_template` | Проверяет макет на ошибки: ссылки, границы, имена областей, область печати |
| `edit_template` | Правит макет (см. ниже) |

`edit_template` умеет:

- добавлять, менять и удалять области;
- превращать ячейки в параметры, шаблоны или текст, задавать параметры
  расшифровки;
- менять оформление диапазона: шрифт, выравнивание, цвета, рамки, формат
  (`ЧДЦ=2`, `ДФ=dd.MM.yyyy`), защиту;
- вставлять и удалять строки и колонки — области, объединения и картинки
  сдвигаются вместе с ними;
- объединять и разъединять ячейки, менять ширины и высоты;
- настраивать печать: ориентацию, масштаб, поля, бумагу, область печати;
- задавать колонтитулы с номером страницы, датой и временем.

После каждой правки превью обновляется, так что агент сразу видит результат.
Всё, что не затронуто правкой, остаётся в файле как было.

### Как запретить правку

Если макеты вы правите другими средствами, запустите сервер с флагом
`--no-template-edit-tools`: `edit_template` исчезнет, а просмотр, конвертация и
проверка останутся. Инструмент занимает меньше места в контексте агента.

## Правка управляемых форм

Агент может менять форму по просьбе обычными словами:

- «Добавь на форму поле Комментарий под Организацией»
- «Перенеси кнопку Заполнить в командную панель таблицы Товары»
- «Сделай поле Контрагент на всю ширину и убери заголовок»

| Инструмент | Что делает |
|---|---|
| `list_form_elements` | Дерево элементов: имя, вид, родитель, путь к данным |
| `validate_form` | Проверяет форму: уникальность идентификаторов, служебные узлы элементов, пути к данным и реквизиты, команды кнопок, обработчики событий |
| `edit_form` | Правит форму (см. ниже) |

`edit_form` умеет:

- менять свойства элемента или формы: заголовок, видимость, ширину,
  растягивание, положение заголовка, группировку, цвет, шрифт, картинку;
- добавлять элементы — служебные узлы (контекстное меню, расширенная
  подсказка, панели таблицы) и идентификаторы создаются сами;
- переносить элементы в группу, на страницу, в таблицу или командную панель;
- удалять элементы вместе с вложенными;
- добавлять, менять и удалять реквизиты формы (с типом, в том числе
  реквизиты-таблицы с колонками) и команды формы.

Удаление элемента, реквизита или команды, на которые что-то ссылается,
агент получит отказом — если только явно не попросить удалить всё равно.

Форма правится точечно: меняются только затронутые узлы, остальной файл
(кодировка, переводы строк, отступы, порядок) остаётся как был. Путь можно
передать и на описатель `Forms/Имя.xml`. Открытое превью обновляется после
каждой правки.

Не правятся список выбора, таблицы ролей и функциональных опций и модуль формы:
процедуры-обработчики агент пишет обычными средствами.

### Как запретить правку форм

Флаг `--no-form-edit-tools` скрывает `edit_form`; просмотр, `list_form_elements`
и `validate_form` остаются.

## Параметры запуска

| Параметр | Назначение |
|---|---|
| `--stdio` | Режим работы MCP (обязателен) |
| `--root <папка>` | Разрешённая папка; можно повторять |
| `--allow-any-path` | Разрешить любые пути — используйте осознанно, правка форм и макетов тоже получит доступ везде |
| `--no-template-edit-tools` | Скрыть `edit_template` |
| `--no-form-edit-tools` | Скрыть `edit_form` |
| `--no-open-browser` | Не запускать браузер: превью откроет сам клиент по адресу |
| `--max-bytes <n>` | Максимальный размер файла (по умолчанию 64 МБ) |
| `--version` | Версия сервера |

## Если что-то не работает

- **«Path is outside the allowed roots»** — добавьте нужную папку через
  `--root`.
- **Сервер подключён, но агент его не вызывает** — включите инструменты
  сервера в настройках агента и попросите явно: «покажи форму визуально, не
  открывай XML».
- **«Браузер не найден»** — установите Edge или Chrome.
- **Не удаётся обновить сервер** — завершите процесс `1c-form-viewer.exe`
  (закройте агента) и замените содержимое папки, не меняя путь в настройках.
- Одновременно открыто одно превью: новое `open_preview` заменяет предыдущее.

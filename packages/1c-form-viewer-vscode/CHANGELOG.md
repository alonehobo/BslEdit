# Changelog

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — [SemVer](https://semver.org/lang/ru/).

## [0.3.0] - 2026-09-26

### Added
- Вложенный MCP-сервер той же версии, что отдельный: `open_preview` с
  `base_path` / `base_revision` показывает сравнение форм, макетов и СКД;
  при `audience="user"` сравнение открывается во внутреннем браузере VS Code.

### Changed
- Общее ядро превью обновлено до той же версии, что BSLEdit и MCP-сервер:
  формы с интерфейсом 8.5 (`Version85`) показывают картинки платформы 8.5,
  включая «Историю данных» и «Справку»; при отсутствии картинки — монохромный
  значок 8.5 вместо PNG Taxi.
- Снято ограничение `os` в манифесте: платформу пакета задаёт `vsce --target`.

## [0.2.3] - 2026-09-18

### Added
- Правка управляемых форм: MCP-инструменты `list_form_elements` (дерево элементов),
  `validate_form` (идентификаторы, служебные узлы элементов, пути к данным и
  реквизиты, команды кнопок, обработчики событий) и `edit_form` — свойства
  элемента и формы, добавление, перенос и удаление элементов, реквизиты формы
  (с типами и колонками реквизита-таблицы) и команды формы. Правка точечная:
  вне затронутых узлов `Form.xml` не меняется; путь можно передать на описатель
  `Forms/Имя.xml`, открытое превью обновляется.
- Настройка `1cFormViewer.mcp.formEditTools` отключает правку форм; просмотр,
  `list_form_elements` и `validate_form` остаются.
- Встроенный MCP-сервер публикуется по HTTP (`http://127.0.0.1:47391/mcp`,
  настройки `1cFormViewer.mcp.http.enabled` и `1cFormViewer.mcp.http.port`) для
  Claude Code, Cursor, Codex и других агентов, пока открыт VS Code.
- MCP-инструмент правки макета `edit_template` (области, параметры с расшифровкой,
  оформление, строки и колонки, объединения, размеры, печать, колонтитулы) вместо
  отдельных `set_area`/`set_parameter`; `validate_template`; `list_markup` по областям.
- Конвертер xlsx переносит числовые форматы и форматы дат, параметры страницы,
  область печати и картинки.
- Настройка `1cFormViewer.mcp.templateEditTools` отключает инструменты правки макета.
- MCP-инструмент `convert_xlsx_to_template` собирает макет печатной формы из `.xlsx`.
- Панель элементов в браузерном preview можно скрыть кнопкой `☰` и вернуть без
  перезагрузки формы.
- Двуязычные описания `open_preview` и инструкции MCP явно направляют агента
  к визуальному макету формы вместо XML и запуска 1С.
- README содержит отдельные инструкции подключения для VS Code Agent/GitHub
  Copilot, Codex IDE extension, Cursor, Claude Code extension и других
  агентских расширений со своим MCP-каталогом.

### Changed
- Инструменты превью сжаты: `open_preview` и `capture_preview` остались
  отдельными, остальные (`inspect`, `select`, `switch_tab`, `scroll`, `reload`,
  `url`, `close`) — операции одного инструмента `preview`.
- Встроенный MCP агента открывает форму во внутреннем Simple Browser VS Code,
  а не в системном браузере.
- Кнопка, Command Palette и контекстное меню используют ту же native-страницу
  во внутреннем браузере вместо отдельного WebView расширения.
- Расширение регистрирует MCP provider после `onStartupFinished`, сохраняя
  командную активацию как дополнительный путь.
- `open_preview` возвращает `requestedPath`, `resolvedPath`, `previewUrl`,
  `kind`, размер и кодировку через structured content и понятный текстовый
  fallback.
- Ошибка файла вне разрешённых корней подсказывает настройку
  `1cFormViewer.mcp.additionalRoots` и standalone-флаг `--root`.

### Fixed
- Цвет рамок из `Template.xml` (`borderColor`) больше не теряется.
- Нативный MCP теперь действительно преобразует
  `Forms/ИмяФормы.xml` в `Forms/ИмяФормы/Ext/Form.xml`; прежняя проверка
  сравнивала полное имя файла со строкой `.xml` и никогда не срабатывала.
- Вложенный layout повторно проверяется после canonicalization, поэтому junction
  или symlink не может вывести чтение за разрешённый корень.

## [0.2.2] - 2026-09-11

### Changed
- Компоновка формы строится по метаданным (`Form.xml`, метаданные объекта,
  `StyleItems`) вместо эвристик по именам: типы, подписи, размеры, растягивание,
  цвета и варианты переключателей берутся из исходников.

### Fixed
- Выбор элемента в дереве структуры теперь подсвечивает и прокручивает элемент
  в визуальном представлении, не переводя фокус в редактор XML.
- Чтение документа, завершившееся позже более нового, больше не публикуется
  в webview.
- Состояние свёрнутых групп и выбранной вкладки сбрасывается при открытии
  другого файла, а не при каждом изменении текста.
- Цикл в цепочке `StyleItems` не роняет рендер формы, а ссылка `style:`
  резолвится независимо от регистра и префикса.
- Выравнивание контейнеров, варианты выбора и подписи-заглушки рендерятся по
  исходнику: скрытые страницы не растягивают предков, `MaxHeight` ограничивает
  многострочное поле, `Height=1` остаётся одной строкой.
- Табличные документы и MXL: строки с авто-высотой больше не обрезаются,
  параметры ячеек не угадываются по тексту.

## [0.2.1] - 2026-09-10

### Changed
- В описание Marketplace добавлен скриншот кнопки открытия визуального preview
  формы в заголовке редактора VS Code.

## [0.2.0] - 2026-09-10

### Added
- В VSIX встроен компактный нативный `1c-form-viewer` MCP; VS Code Chat
  автоматически получает его через `McpServerDefinitionProvider`.
- По умолчанию MCP читает только текущие workspace-папки. Добавлены настройки
  дополнительных разрешённых корней, полного доступа к абсолютным путям и
  отключения регистрации сервера.

### Changed
- Минимальная версия VS Code поднята до 1.101 — первой стабильной версии API
  регистрации MCP-серверов из расширений.

### Fixed
- Открытие дескриптора формы `Forms/ИмяФормы.xml` теперь показывает саму форму
  (`ИмяФормы/Ext/Form.xml`), как это давно делал MCP-сервер. Раньше расширение
  отвечало «файл не распознан».
- Пустая командная панель таблицы с `Autofill=false` больше не оставляет строку
  с поиском и кнопкой «Еще».
- Встроенный нативный MCP возвращает валидный JSON для успешных вызовов.

### Changed
- Рендереры, реестр форматов и правила чтения файлов 1С берутся из общего
  пакета `1c-preview-core`; в расширении больше нет ни своей копии декодера
  кодировок, ни своей ветки распознавания формата.
- Список ассетов вебвью генерируется из манифеста ядра, а не перечисляется в
  `extension.js`.
- Добавлен `vscode:prepublish`: `vsce package` больше не может собрать `.vsix`
  из устаревшего `media/`.

## [0.1.0] - 2026-09-10

### Added
- Первый выпуск: визуальный read-only предпросмотр `Form.xml`, `Template.xml`
  и `.mxl` в панели VS Code, с деревом структуры и переходом к исходнику.

## [0.2.3] - 2026-09-18

### Added
- Правка управляемых форм: MCP-инструменты `list_form_elements` (дерево элементов),
  `validate_form` (идентификаторы, служебные узлы элементов, пути к данным и
  реквизиты, команды кнопок, обработчики событий) и `edit_form` — свойства
  элемента и формы, добавление, перенос и удаление элементов, реквизиты формы
  (с типами и колонками реквизита-таблицы) и команды формы. Правка точечная:
  вне затронутых узлов `Form.xml` не меняется; путь можно передать на описатель
  `Forms/Имя.xml`, открытое превью обновляется.
- Флаг `--no-form-edit-tools` скрывает `edit_form`; просмотр, `list_form_elements`
  и `validate_form` остаются.
- MCP-инструмент правки макета `edit_template` (области, параметры с расшифровкой,
  оформление, строки и колонки, объединения, размеры, печать, колонтитулы) вместо
  отдельных `set_area`/`set_parameter`; `validate_template`; `list_markup` по областям.
- Конвертер xlsx переносит числовые форматы и форматы дат, параметры страницы,
  область печати и картинки.
- Флаг `--no-template-edit-tools` скрывает инструменты правки макета.
- MCP-инструмент `convert_xlsx_to_template` собирает `Template.xml` из `.xlsx`
  и открывает preview.

### Changed
- Инструменты превью сжаты: `open_preview` и `capture_preview` остались
  отдельными, остальные (`inspect`, `select`, `switch_tab`, `scroll`, `reload`,
  `url`, `close`) — операции одного инструмента `preview`.

### Fixed
- Цвет рамок из `Template.xml` (`borderColor`) больше не теряется: серые рамки
  рисовались чёрными.

### Removed
- Удалены npm/Node MCP, portable-обёртка со встроенным Node.js и compact-
  установщик. Единственный поддерживаемый сервер — нативный Windows EXE.

## [0.2.0] - 2026-09-10

### Added
- Добавлен самостоятельный нативный Windows x64 MCP-сервер.
- Добавлен строгий round-trip контрактный тест нативного STDIO-протокола.

### Changed
- Рендереры форм и макетов переехали в общий пакет `1c-preview-core`; сервер
  собирает `build/web` из него по единому манифесту, а не из каталога плагина
  Total Commander. Спрайт иконок берётся из `icons.svg`, а не выдирается
  регэкспом из `web/viewer.html`.
- Правила чтения файлов 1С (кодировки, дескрипторы форм, метаданные объекта)
  общие с расширением VS Code — один и тот же файл открывается одинаково.
- Версия сервера берётся из `package.json`: `--version`, `--help` и
  MCP-рукопожатие не расходятся между собой.
- Сборочные скрипты ищут MSVC и Windows SDK через `vswhere`, а не по
  прибитому пути к конкретной версии тулчейна.
- Скриншот навигационной операции снимается атомарно с её результатом;
  `inspect_preview` ограничивает объём ответа.

### Fixed
- Успешный `tools/call` нативного сервера снова возвращает валидный JSON.
- `scroll_preview` больше не повреждает строковые значения заменой текста в
  сериализованном JSON.
- Пустая командная панель таблицы с `Autofill=false` полностью скрывается
  вместе с поиском и кнопкой «Еще».
- Edge корректно закрывается при ошибке инициализации; loopback-сервер отклоняет
  запросы с непетлевым заголовком `Host`.
